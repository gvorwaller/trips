# 2026-07-03

## Duplicate day-plan stops (td-9f9807)

Fixed the duplicate route-stop path behind stale trip notes and Google Maps route-generation failures.
Day plans now reject duplicate stops by physical location rather than title: same itinerary item, same
Google `place_id`, or coordinates within 30 meters. The same validation also checks route anchors, so
an anchor cannot duplicate a saved stop.

Added clear action failures for duplicate adds from the saved-plan picker, day-plan builder, and
suggested-stop buttons. Existing bad data is also guarded at route-calculation time: duplicate
coordinates now fail before calling Google Directions, with a message to remove duplicate stops.
